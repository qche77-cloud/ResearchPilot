- 服务内后台线程与 SQLite 持久消息队列；关闭浏览器可继续，服务重启后手动恢复。

- 可编辑/清除长期偏好，近期对话＋早期摘录上下文。
- 引用校验不等于语义事实核验；财务单位未统一，不做自动估值或买卖决策；实时行情、自动下单不在本版。

## 操作注意

- 研究服务需要联网权限；沙箱内启动曾导致 WinError 10013。启动命令：
  .\.venv\Scripts\python.exe -m streamlit run agent_app.py --server.address 127.0.0.1 --server.port 8502 --server.headless true --browser.gatherUsageStats false
- Streamlit 热更新曾缓存旧模块，新函数导入失败时需完整重启服务，并验证页面执行。
- SQLite：data/researchpilot.db，保留用户研究记录，不为测试覆盖或删除。
- 不应为了验证普通 UI 修改反复消耗真实模型和搜索额度；优先离线测试。
