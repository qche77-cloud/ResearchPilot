# ResearchPilot Agent 开发记录

日期：2026-09-14

## 一、产品定位

将一次性生成报告的研究工具，逐步升级为面向个人 A 股投研的对话式助手：围绕公司持续提问、查询证据、记录假设，并在新信息出现时修正判断。当前用于盘后研究，不提供自动交易，也不将模型结论视为投资保证。

## 二、已完成的主要能力

### 对话与研究执行

- 支持连续对话、追加研究要求，以及根据新要求重新规划。
- 对话默认展示简短结论，完整报告和证据通过按钮打开，避免报告占满聊天区。
- 报告保留版本，历史消息尽量关联其对应版本；无法核实的旧内容明确说明。
- 后台执行研究，支持暂停、恢复和追加搜索预算。关闭浏览器不等于停止研究；服务重启后需手动恢复。
- 默认成功搜索预算保持为 2，便于测试；失败搜索不计入成功次数。
- 区分完成、部分完成和失败，显式提示证据缺口。

### 个股研究工作台

- 接入 A 股日线、收盘走势、日 K 线及财务原始数据，注明来源、获取时间与交易日期。
- 支持股票名称和代码查询；目录可本地缓存、手动更新。此前实测缓存 5,562 条，英维克匹配 002837。
- 财务摘要支持报告期选择，公司对比采用共同报告期及统一展示逻辑。
- 只有数据源明确单位时才换算金额；未知单位保留源值并标注“单位待核对”，不自动估值。
- 网络、超时和数据校验失败给出可读提示，保留历史快照，不伪造新数据。
- 支持自选股、快照变化、投资假设、催化因素、证伪条件和复盘记录。
- 可选盘后更新默认关闭，仅在本地服务运行时执行，变化在应用内展示。

### 记忆与证据

- 对话与研究状态保存在本地 SQLite，明确保存的长期偏好可编辑或删除。
- 追问使用最近消息和较早消息摘录，不是无限上下文，也不是完整语义记忆系统。
- 引用编号与摘录校验用于检查引用是否对应资料；不等于已经验证推理正确或信息足够新。

## 三、界面与交互

- 主视觉调整为深蓝侧栏、浅色工作区和蓝紫强调色。
- 首页重排为居中标题、三个研究方向入口及内嵌输入区；入口先生成可编辑草稿，提交后才执行研究。
- 对话采用单列布局，研究控制和工具详情默认收起。
- 增加导航标题入场、弹窗入场、卡片悬停和输入框聚焦反馈，支持减少动态效果偏好。

- 当前仍采用 Streamlit，轻量动效不等于完整无刷新转场，独立前端尚未实现。
