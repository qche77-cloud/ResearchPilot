# 2026-10-14：量化研究基础第一阶段交付

本阶段完成日期边界与行情质量修复，以及可运行的单公司财务体检、自选股财务筛选。继续复用现有 Streamlit、SQLite、财务计算和后台 Agent。没有新增表或破坏性迁移，不覆盖密钥、不删除数据、不执行真实交易。本阶段不是历史策略回测或完整量化平台。

## 实际实现

1. 财务 `published_at` / `available_at` 校验：格式错误、披露早于财报期末、披露/可用日期晚于采集日期、可用日期早于披露日期均阻断相关记录。
2. `normalize_financials(..., as_of=...)`、`analyze_financials(..., as_of=...)` 支持日期级截面：缺少披露日期、尚未可用或报告期晚于截面的记录阻断。不可用的后续修订不会使截面内旧值变成冲突；截面内存在多个矛盾值时仍阻断，不擅自挑选版本。
3. 历史估值优先选择市值日期之前已披露且可用的匹配分母，再计算 PE/PB；归母口径、币种、实体、年度/TTM/时点条件继续校验。没有可用财报时保留阻断原因。
4. 单季度和 TTM 派生值保留输入最晚披露/可用日期，研究财务快照保留这些日期及 as_of；证据导出同样记录截面。
5. 日线拒绝非有限/缺失数值、非正价格、负成交量、矛盾 OHLC、重复/无效日期和超出查询日期的记录。合法零成交量保留，排序不修改调用者输入，不静默去重或修复错误价格。
6. 财务体检提供五项可追溯指标：营业收入同比、归母利润同比、毛利率、净利率、同范围现金流 TTM / 净利润 TTM。分母缺失或非正、口径不同、未披露等明确不可计算；不使用归母利润替代合并净利润计算现金兑现率。
7. 显式条件筛选本地股票池：最多 50 家，输入股票与代码匹配，日期/口径/币种/范围一致；页面提供收入和归母利润同比下限，结果显示匹配、未匹配原因、财报期及可计算项。Python 模块支持五项指标的下限条件，但页面不谎称已有综合评分或行业自动排名。
8. 体检结果作为结构化证据接入现有 Agent；筛选匹配后，用户可显式启动个股核查。筛选本身无数据刷新、模型或搜索调用。虚构演示没有真实研究按钮，不能保存为真实财务输入。

## 使用入口

- 本轮新服务地址：`http://127.0.0.1:8506`，原有服务进程未停止。启动前只读确认启用监控数量为 0；新服务不会自动恢复研究。
- **个股与自选 → 个股与复盘 → 财务分析 → 财务质量体检**：读取既有独立财务输入或快照，选择截面、口径、币种和范围；导出完整公式和输入记录。
- **个股与自选 → 财务筛选**：从自选股已有数据筛选，或勾选离线虚构股票池演示。修改条件后重新运行；结果注明实际运行条件，避免将旧结果误认为新筛选。
- 数据缺少 `published_at` 时，原普通财务展示/计算保持兼容，但严格体检与历史截面不会声称数据当时可用。旧数据不会被自动补造披露日期。
- UI 表格保留两位小数，证据下载保留 Decimal 精确字符串；缺失值不补零。

```powershell
.\.venv\Scripts\python.exe -m streamlit run agent_app.py --server.address 127.0.0.1 --server.port 8506
.\.venv\Scripts\python.exe -m scripts.run_offline_tests --output artifacts/quant-foundation-regression-2026-10-14.json
```

## 未完成项与下一步

- `as_of` 为日期级包含边界，不支持盘中时间排序、自动公告确认、下一交易日生效或完整修订历史仓库。录入的披露/可用日期是来源元数据，需要用户/数据适配器核实；多个同时可用的冲突版本保守阻断。
- 行情仍为近 180 个日历日、不复权；未新增交易日历、停牌识别、历史股票池、股本/复权因子、涨跌停成交或成本模型。因此没有回测收益。
- 筛选只使用已有本地输入，未拉取 20–50 家真实同业数据；没有自动行业分类、综合排名、ROE/ROIC 或完整资产负债表指标。
- 多进程租约/CAS、语义 Verifier、阅读器网络边界、总调用/费用预算和公告订阅仍待实施。多个服务进程共享同一库时应保持单一执行入口，不能声称跨进程并发已经安全。
- 下一阶段优先补任务所有权与版本写入保护、数据适配器和明确行业股票池，再建立研究兑现记录；历史回测须在数据条件成立后单独验收。
