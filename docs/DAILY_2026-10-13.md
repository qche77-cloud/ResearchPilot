# 2026-10-13：ResearchPilot v2 升级、验收与发布记录

本报告记录 2026-10-12 至 2026-10-13（北京时间）的实际开发、测试和 GitHub 同步结果。当前交付为经过离线验证的开发版本，不是完整生产认证或正式版本标签。

## 本次实现

- 评测与可观测性：标准合成案例、离线回归入口、模型/工具调用轨迹、耗时、可用 Token 用量及显式费率下的估算费用；未知用量或费率不填造数值。
- 财务分析：确定性同比、累计转单季、环比、利润率、TTM、PE/PB；约束财报期、币种、单位、合并范围、来源与更新时间，提供输入追溯和可视化。
- 自主研究：结构化假设、支持/反对证据、未解决问题和不确定性；两个财务背离规则触发补充任务，限制预算、迭代和重复查询。
- 证据与验证：结论、假设、证据、来源关系图；检查引用完整性、有限数值冲突和显式财务反例遗漏，通用语义支持保留 unknown。
- 持续研究：同公司历史基线、不可变版本、财务修订、假设失效和报告差异；可配置监控开关、频率、来源及成功/部分成功/失败记录。
- 兼容性：复用 ResearchState、Streamlit 和 SQLite，采用新增表和独立财务输入版本，无破坏性迁移、密钥覆盖或真实交易。
