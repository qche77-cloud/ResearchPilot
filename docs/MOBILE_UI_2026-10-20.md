# 手机端界面优化与验收

日期：2026-10-20。保留深色金融风格，重点调整布局、阅读和操作。所有截图与写入测试均使用独立的临时虚构库。

## 实际功能

| 页面 | 修改 |
| --- | --- |
| 研究首页 | 紧凑品牌栏、可展开演示说明、问题入口、快捷题目、统计、搜索与状态筛选、加载更多 |
| 新建研究 | 底部面板、草稿保持、提交锁、网络失败后重试沿用原请求标识 |
| 报告 | 报告/证据/过程分段、版本切换、章节目录、持久化阅读字号、句内引用定位 |
| 证据 | 原文摘录、来源日期、完整文本折叠、复制来源与 HTTP 兼容路径 |
| 公司财务 | 财报期/币种/报表口径分组、四项已有指标卡、收入图点选、原始记录详情 |
| 自选与账号 | 可点击公司行、管理面板、配额与阅读设置、独立演示账号 |
| 通用交互 | 浮动导航、返回和滚动恢复、底部面板焦点圈定/背景 inert、减少动态效果、safe area |

浏览器收入曲线按币种、期间口径、报表范围和单位分组。原生轻量条形图展示同组同年的收入源值。金额显示保留精确字符串，Number 仅用于图形坐标；不在前端增加财务推导。`currency_unit` 展示为对应币种的基本单位，百分比展示为 `%`，原始数值及 raw_unit 保留。

新建任务或修改自选成功后，首页缓存失效并重新读取，避免返回时看到旧列表和计数。页面跳转清除上一页的短提示；迟到的报告版本响应不会覆盖当前选择。

## 修改文件

- `mobile-preview/index.html`、`mobile.js`、`mobile.css`：新的手机浏览器界面；已移除不再引用的旧脚本与样式。
- `miniprogram/mobile.wxss`、`app.wxss`：原生样式与布局。
- `miniprogram/pages/{home,task,company,watchlist,account,login}/`：原生页面、目录、来源和筛选控制器。
- `miniprogram/utils/format.js`：精确金额、单位和口径展示。
- `scripts/check_mobile_ui.py`：自行创建/关闭临时演示服务，拦截非本地浏览器请求。
- `scripts/check_miniprogram_browser.py`：适配新交互、减少动画、截图等待提示消失。
- `scripts/check_mini_client.cjs`：新增控制器、来源分组、金额精度和单位测试。

## 验收边界

原生微信页面只通过静态和控制器测试，尚未经过开发者工具编译或实体手机验收。浏览器结果不等于微信运行结果。真实微信凭证、HTTPS 域名、体验码仍需配置；真实模型与行情服务本轮没有调用。

原桌面服务和手机局域网演示没有被重启。用户可刷新原网页加载新静态资源；局域网地址随电脑 IP 改变，不是公网服务。移动与桌面资料当前独立，无自动同步或移动财报上传。
