# 2026-09-20：个股持续研究第一版

## 本次交付

- 个股档案：关注点、支持证据、反面证据、待核查问题。投资假设继续使用原来的复盘表，不复制或自动覆盖用户判断。
- 研究绑定：单一名称/代码可关联个股；多公司或跨股票追问给出明确提示，避免原主题中的股票覆盖新问题的行情上下文。
- 更新入口：工作台“更新这家公司”、自选股“研究最新变化”、已绑定对话“基于档案更新研究”。每次创建独立研究，默认搜索预算仍为 2。
- 固定基线：保存上次已完成报告的版本、时间与简述，可查看基线报告和打开历史任务，不覆盖旧报告。
- 更新摘要：区分更新进行中、失败、无基线、未找到可确认的新来源及发现新来源候选。展示与新来源关联的分析供用户核对，不自动确认判断变化。
- 时效提示：分开显示查询时间、行情日期、财报期间、公告/来源日期；未知和未来日期明确提示。结构化数据 7/180 日提醒阈值只是日历日启发式，不是交易日历或披露期限判断。
- 历史搜索：按主题中的公司名、代码或关键词搜索，显示最多 50 条结果。
- 草稿：新研究与不同对话各自保留草稿，支持当前浏览器会话内切换页面；刷新/关闭浏览器不保证保留。

## 实现边界

- 旧研究通过明确关联或最近 200 条代码匹配的单股任务复用；名称型旧任务仍可从侧栏搜索，未做全历史自动实体消歧。
- “新来源候选”按新 URL 和晚于基线的日期筛选，不代表已验证新公告；同日发布、同 URL 更新、日期缺失的信息不会被自动认定为新增。
- 观点的支持/削弱由报告分析提出，用户自行核实后编辑档案。当前没有自动把模型判断写回投资假设，也没有经过独立事实审计的自动评级。
- 未知财务单位不换算，单季/累计口径需核对；没有引入自动财务口径映射、付费数据源或自动交易。
- 保留 Streamlit 界面；本轮不是独立前端重构。

## 验证

- 28 项离线测试通过，覆盖档案隔离、旧假设保留、基线引用、日期异常、失败与未找到新信息的区别、跨股拦截及更新按钮。
- AppTest 验证首页草稿跨页面保留和档案页运行。没有触发新的付费研究请求；尚未进行真实联网端到端研究验收。
- 旧的 2026-09-14 开发记录保留。本轮不自动提交或推送 GitHub。
