## 实际修改

- `scripts/serve_miniprogram.py`：新增 `--lan-demo`，仅允许演示模式显式绑定单个 RFC1918 私有 IPv4；默认回环限制保留，拒绝通配、公网、链路本地等地址。
- `src/mini/config.py`、`src/mini/api.py`：明确标记 LAN demo，正式配置拒绝启用此标志。
- `mobile-preview/app.js`：HTTP 环境不要求 `crypto.randomUUID`；仍生成稳定重试使用的请求标识。来源复制优先 Clipboard API，不可用时降级，并显示可长按复制的来源地址。认证 token 仍由服务端安全随机生成，未改为客户端生成。
- `scripts/test_mini_core.py`：新增绑定准入与配置隔离回归。
- `scripts/check_miniprogram_browser.py`：显式允许 LAN demo 验收，检查非安全 HTTP 上下文，并禁用新剪贴板/UUID API 验证降级流程。
- `miniprogram/README.md`：新增手机同 Wi-Fi 操作方式与微信接入的区别。

演示仍只操作临时虚构数据，不调用微信、模型、搜索或行情 API，不读取桌面历史。独立 A/B 演示账号只用于体验，不作为正式账号登录方式。
