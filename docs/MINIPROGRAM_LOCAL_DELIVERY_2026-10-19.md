## 实现的功能

- 一次性、限时邀请；微信临时凭证由后端交换，应用会话使用随机 bearer token，仅哈希落库，支持过期、退出和停用。
- 微信正式服务禁止演示登录；演示服务禁止微信登录。登录失败不替换成模拟成功。服务器默认不启用真实研究。
- 服务端生成内部用户 ID，并映射至独立 SQLite 研究库/工作台。前端不能选择数据库路径、任意用户或扩大预算。
- 任务创建、历史分页、状态、暂停/恢复、指定报告版本、原始证据、自选维护与已有财务数据读取。
- 创建请求幂等、搜索与迭代上限、单人/全局并发、每日新建与恢复次数限额、账号总数上限、登录/API 限流、请求体大小限制。
- 新 API 使用现有 Python 引擎、Runner、报告快照和 Decimal 财务逻辑。新增真实 Runner 的离线接口集成测试，核对调用方工作台传入及持久命令消耗。
- 单进程数据目录锁；进程重启后恢复为待人工恢复，不自动重复发起模型调用。
- 深色单栏原生页面：研究、自选、任务/报告/证据/过程、公司财务、账号、登录。离开页面后停止轮询，忽略迟到的请求；网络重试沿用请求标识。
- 所有移动端时间按 Asia/Shanghai 展示。财报期间、币种、单位、口径和来源保留；没有来源的缺口不填补。
- 显式的临时虚构浏览器预览，独立于原生微信运行环境。A/B 账号可验证数据隔离，不调用外部研究服务。

## 外部依赖与限制

仍需配置 AppID/AppSecret、可访问的 HTTPS 服务和微信域名/体验成员，之后运行微信开发者工具与真机验收。没有获得这些外部条件，本次不宣称“微信版可直接扫码使用”。微信当前主体、类目、备案或公开发布材料尚未核验，沿用前置报告中的核验状态。

小范围版本按单服务进程运行，不支持分布式调度或多机 SQLite。每人独立库的备份、账号停用及配额由部署者管理。新旧桌面历史同步、财报上传、主动通知与公开注册仍未实现。

费用限额是次数/并发/迭代边界，不是金额硬限额；现有用量或价格缺失时继续标记费用未知。离线开发与验收没有消耗真实模型费用。
