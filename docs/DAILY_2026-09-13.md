# ResearchPilot 开发记录｜2026-09-13

## 今日目标
将固定研究流水线升级为面向个人 A 股投研的对话式 Agent，兼顾证据追溯、个股数据和持续复盘。

## 已完成
1. 重建项目 Python 3.11.4 虚拟环境并安装依赖，修复旧 Python 3.7 环境与代码不兼容的问题。
2. 新增 Agent 循环：按证据缺口选择搜索、阅读、综合和交付；支持目标化规划、追加要求、重新规划和预算控制。默认搜索预算暂为 2，供测试。
3. 改为连续对话入口。对话默认简短总结，报告和证据通过入口打开；历史长回答保留原文并折叠，保存报告版本。
4. 修复顶部遮挡、旧模块热更新导入错误及 SQLite 连接未关闭问题。
5. 修复失败搜索扣预算、调整方向未更新计划的问题。交付区分完整完成、部分完成和无有效结论失败。
6. 加入引用编号和原文摘录校验；引用不匹配时最多修正一次，仍失败则不展示该结论。无法核实版本的旧回答不强行关联当前报告。
7. 加入服务内后台线程和 SQLite 持久消息队列：切换页面或关闭浏览器可继续研究，当前工具结束后处理追加消息；服务重启后需手动恢复。
8. 新增个股工作台：A 股日线、K 线、财务原始指标、同报告期对比、数据快照下载。接入 AKShare/东方财富日线及新浪财务数据。
9. 新增自选股、快照变化比较、可选工作日盘后自动更新。自动更新默认关闭，变化仅记录在应用内。
10. 新增投资假设、预期催化、证伪条件、复盘记录及 Agent 核查入口。
11. 新增可保存、编辑、清除的长期偏好；对话提供最近消息及较早消息摘录。
