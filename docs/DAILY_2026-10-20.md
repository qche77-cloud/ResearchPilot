## 隐私、费用与发布

本轮没有真实模型、Tavily、行情、微信登录请求，也没有交易。所有写入验收使用独立临时库；正式数据库、密钥和原有服务保持不变。公开截图全部为虚构数据。`.env`、微信本地私有配置、数据库、运行状态和日志不纳入提交。

发布前执行 `python -m scripts.check_publish_safety` 扫描完整暂存树，并检查截图来源与文档链接。只上传经过白名单选取的源码、测试结果、报告和演示截图。

发布检查的四个离线用例验证了正常文件通过、私有文件拒绝、常见密钥特征拒绝和本地凭据精确匹配拒绝。首轮完整暂存树扫描 538 个文件，零发现；最终范围与结果见[发布扫描记录](../artifacts/publish-safety-2026-10-20.json)。七份主要展示/交付文档的本地链接均有效；原手机网页、本机演示和电脑服务只读健康检查均为 HTTP 200，新静态资源已可访问。

为遵守用户“不用我的钱”的要求，提交使用 `[skip ci]`，不主动启动可能计费的 GitHub Actions；本报告的通过结果均来自本地验收，不声称新增云端 CI 已通过。真实研究在日后显式启用时仍可能产生模型/搜索费用，次数配额不是金额硬上限。

GitHub 普通直连曾超时；只读预检使用系统已配置的本机代理后成功。一次无具体内容的 GitHub blob 请求被自动审批拒绝，没有写入；后续采用明确文件白名单和扫描后的 Git 提交发布，不绕过敏感内容审查。

发布后的提交与远端确认单独记录在 [发布回执](PUBLICATION_2026-10-20.md)。
